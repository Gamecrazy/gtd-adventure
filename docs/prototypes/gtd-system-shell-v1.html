母版 v1 · 审阅说明

本轮只验证什么

保留白色、高密度的 GTD 工作台，在顶部、方向坐标、当前行动和状态反馈中增加一层克制的系统界面感。

可以操作

  • 切换右上角“系统层”，比较包装前后。
  • 点击“标记完成”或列表勾选，查看轻量反馈。
  • 点击五个 GTD 阶段，观察全局阶段表达。

本轮刻意不做

不设计积分、等级、地图或助手对话；不改变 GTD 概念；不把原型中的合成内容当作真实数据或产品决定。

审阅时只问三个问题

  • 它是否仍然像一套可信的 GTD 工具？
  • 系统层是否让方向与阶段更可感知？
  • 哪些元素产生了噪声，应当删掉？
